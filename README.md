# Lu Research Homepage

一个不依赖框架和构建工具的极简科研个人主页。

页面采用 Academic Pages 风格的顶部导航与双栏学术主页结构，并根据个人用途精简为简介、研究方向和联系方式。

## 文件结构

```text
index.html              主页内容
404.html                404 页面
assets/style.css        页面样式
img/                    图片与图标
THIRD_PARTY_NOTICES.md  模板来源与许可说明
```

推送到 `master` 后，GitHub Actions 会自动部署到：

https://lulili520.github.io
